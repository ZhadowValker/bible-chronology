# Chronicles — Bible Chronology

A self-contained static Bible chronology explorer containing 556 events, filters, search, card and list views, dark mode, and linked source chapters.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Rename `Bible_Chronology_Web_Page_v2_1789280046106.html` to `index.html`.
3. Upload `index.html` to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.

GitHub will provide the public site URL after deployment.

## Technical notes

- No build step or package installation is required.
- All CSS, JavaScript, and chronology data are embedded in one HTML file.
- The page uses no external fonts, libraries, trackers, or asset CDNs.
- Source chapter links are loaded from `sajeevavahini.com`. If that website prevents iframe embedding, readers can use **Open in new tab**.
